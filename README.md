# Paradise Nursery - Plant Shopping Application

## Project Description

Paradise Nursery is a React-based online plant shopping application that allows users to browse different categories of houseplants and add plants to a shopping cart.

The application provides a simple and user-friendly shopping experience with dynamically updated cart quantities, product prices, and total costs.

## Features

- Plant categories
- Plant images, names, descriptions, and prices
- Add to Cart functionality
- Dynamic cart item count
- Increase and decrease product quantities
- Remove products from cart
- Automatic total price calculation
- Continue Shopping functionality
- Checkout message
- Responsive user interface

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Redux Toolkit
- React Redux
- React Router
- Vite
